# 人物纪实与成长故事

适用于运动员、公开人物的成长、生涯回顾及人物情绪短片。普通新闻仍按原流程制作；不把一个人物样片的色调、镜头数量和速度强加给所有题材。先读取本机已确认偏好及用户当前要求，已有满意版优先沿用。

## 先核事实，再绑定镜头

将口播拆为成长节点及关键动作：年龄或年份、训练、比赛、失利、回应、获奖、观众反应。逐项核对当事人、事件、比赛项目和结果；单打、双打、团体成绩分开，不能把搭档或对手领奖画面当作主角夺冠。不要把文学化描述写成未经证实的经历或心理活动，如练习次数、深夜独坐、从不辩解。

用户上传素材是起点，不是唯一素材库。主动寻找本人早年资料、官方赛事、原始采访、训练及不同阶段画面，下载或查看后再决定区间。高点赞只说明传播表现，不能证明片中事实或使用许可。关键历史节点优先找机构原文和官方素材；转载日期不能当事件年份。

每句至少有一条素材记录，镜头清单至少包含：

| 字段 | 内容 |
|---|---|
| sentence_id / text | 对应完整口播句 |
| timeline_start / end | 成片起止时间 |
| source_id / URL / file | 可追溯来源、原链接和项目相对文件路径 |
| source_start / end | 原素材实际使用区间 |
| person / event / date | 画面中的人物、事件、年份或年龄及其依据 |
| action | 走路、正手、发球、庆祝、采访、领奖等具体动作 |
| match_reason / limitation | 支持哪部分解说、是否同场同年、不能证明什么 |
| crop / credit / audio | 裁切、观众可见署名、是否带同步原声 |

年龄说到五岁，就找可验证为本人五岁的视频，短用约2–5秒即可。找不到时用来源可靠的本人童年照片或明确标注年份的少年资料，承认年龄未确定，不能将少年比赛叫作五岁录像；也不能用别的小女孩或AI角色充当本人。儿童正脸仍遵循原保护要求，优先背影、手部或遮挡，不为还原童年取消保护。

历史资料、非同场训练和回顾镜头在必要位置标明年份、资料性质及用途。事实来源和画面来源分别列出，不用一个署名暗示两者完全一致。当句子承诺具体进球、失利或夺冠时，优先对应事件画面；相关资料不足时缩减承诺或调整稿件，不随意填充。

## 动作推进与情绪

优先使用真实动态，以动作和原始回应推进故事。多数镜头可从2–5秒起选；完整采访、回合或必要阅读可更长，不机械卡时长。图片、时间线和证据卡短暂解释节点，不循环充数，不设固定动态比例或镜头数量。

成长、低谷、赛场和结尾的冷暖变化按题材及用户要求设计，保持肤色、球台和动作可辨；不把调色当作证明人物心境的证据。真实转播动作不以过度慢放、重复播放或静止画面凑分钟数。保留球、球台、对手和关键动作；裁字幕、台标不能改变比赛含义。

检查三层重复：同文件区间重叠；不同下载文件是否其实同一原片；不同时间码是否反复出现同一种动作。多个入场走路、同一采访背景、同类挥拳、同个领奖合影即使区间不重叠，也应删减或用训练、回合、回应等有新信息的动作替换。回放只有解释具体一球才保留并注明。

选区间时看内部切镜及首尾，避免主角庆祝后切到搭档、比赛后切到无关嘉宾、转场动画或儿童特写。原声采访出现口型时，画面的原片起点必须对应已锁定音频的起点，不能拿另一个采访时刻对口型。

## 修改和交付

用户只要求换素材或去重复、口播未变时，不重配音、不整体挪字幕、不更改已满意的封面和关键词样式。先锁定配音、音乐及字幕基准，渲染新画面后复制已满意音轨，检查压缩音频内容及包时间戳一致；容器确有必要偏移时明确记录并同步处理字幕，不能只看音频哈希就声称同步。

新稿或声音改变时重新按实际语音生成句边界，不按字数均分字幕，不用全局偏移修复局部错位。音频可先独立混好再与画面合成；在最终成片核验句子及原声位置，而非只检查中间WAV。声音检查参照[audio.md](audio.md)，抽帧与重复检查参照[qa-privacy.md](qa-privacy.md)。

交付保留逐句素材与镜头表、来源与限制、检查结论、1080p成片、封面、SRT、纯旁白和三平台发布包。旧版归本条历史版本，覆盖或移除前核验归属、备份和哈希；不要删除无关原件。局部换画面后复核发布标题及文案是否仍与实际内容一致。
